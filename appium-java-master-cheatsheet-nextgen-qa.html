1. Full Setup Flow (Order Matters)
Install order for a working Appium+Java rig
1. JDK → JAVA_HOME 2. Node.js → npm install -g appium 3. Android Studio → Android SDK → ANDROID_HOME 4. appium driver install uiautomator2 5. Xcode (Mac only) → appium driver install xcuitest 6. Appium Inspector (standalone app) 7. IDE (VS Code / IntelliJ) + Maven project 8. Java client dependency in pom.xml
2. Java & JDK Setup
Install JDK 11+ & verify
java -version javac -version
Set JAVA_HOME (macOS/Linux ~/.zshrc)
export JAVA_HOME=$(/usr/libexec/java_home -v 11) export PATH=$JAVA_HOME/bin:$PATH
Windows (System Env Variables)
JAVA_HOME = C:\Program Files\Java\jdk-11 PATH += %JAVA_HOME%\bin

node -v && npm -v npm install -g appium appium -v

19. Waits & Synchronization
Explicit wait (recommended)
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(15)); WebElement el = wait.until(ExpectedConditions.elementToBeClickable( AppiumBy.accessibilityId("login")));
Fluent wait w/ polling
Wait<AndroidDriver> fw = new FluentWait<>(driver) .withTimeout(Duration.ofSeconds(20)) .pollingEvery(Duration.ofMillis(500)) .ignoring(NoSuchElementException.class);

23. Page Object Model (Java)
POM with PageFactory + AppiumFieldDecorator
public class LoginPage { AndroidDriver driver; @AndroidFindBy(accessibility = "username") WebElement username; @AndroidFindBy(accessibility = "loginBtn") WebElement loginBtn; public LoginPage(AndroidDriver driver) { this.driver = driver; PageFactory.initElements( new AppiumFieldDecorator(driver), this); } public void login(String user) { username.sendKeys(user); loginBtn.click(); } }

28. Best Practices
Checklist
✔ Accessibility ID/ID over XPath for speed ✔ Page Object Model + PageFactory always ✔ Explicit waits only, never mix w/ implicit ✔ noReset/fullReset controlled per test ✔ Parallel run via TestNG + multiple devices ✔ Screenshot + logs captured on failure ✔ Pin java-client + driver versions together
