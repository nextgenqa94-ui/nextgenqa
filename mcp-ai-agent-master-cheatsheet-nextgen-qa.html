1. Protocol Layers & Lifecycle
JSON-RPC 2.0 message shape
{ "jsonrpc":"2.0", "id":1, "method":"tools/call", "params":{ "name":"get_ticket", "arguments":{id:"QA-1"} } } // notifications = no "id" field, no response expected
Handshake sequence
client → "initialize" {protocolVersion, capabilities} server → returns its capabilities (tools/resources/prompts) client → "notifications/initialized" // only now can normal requests flow
2. Advanced Tool Definition
Structured output + annotations + try/catch
server.registerTool("create_jira_issue", { inputSchema:{project:z.string(),summary:z.string()}, outputSchema:{issueKey:z.string(),url:z.string()}, annotations:{readOnlyHint:false,destructiveHint:true} }, async ({project,summary}) => { try { const i = await jiraApi.create({project,summary}); return {structuredContent:{issueKey:i.key,url:i.url}, content:[{type:"text",text:`Created ${i.key}`}]}; } catch(e){ return {isError:true,content:[{type:"text",text:e.message}]}; } });
