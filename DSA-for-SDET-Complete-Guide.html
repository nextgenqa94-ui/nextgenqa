Time Complexity · Space Complexity · Big O Notation · Analysis Basics
Big O Notation
O(1) Constant
Accessing array element by index. No loop. Fastest
O(log n) Logarithmic
Binary search. Divide & conquer. Very fast
O(n) Linear
Single loop through n elements. Normal
O(n log n) Linearithmic
Merge sort, Quick sort. Good for sorting
O(n²) Quadratic
Nested loops. Bubble sort. Acceptable for small n
O(2ⁿ) Exponential
Recursive without memoization. Very slow
O(n!) Factorial
Permutations. Extremely slow. Avoid

How to Analyze Time Complexity
Step 1: Count Basic Operations
Assignment, comparison, arithmetic — each is O(1)
Step 2: Count Loops
Single loop = O(n). Nested loop = O(n²). Nested 3x = O(n³)
Step 3: Drop Constants
O(2n) = O(n). O(n + 100) = O(n). Only highest order matters
Step 4: Drop Lower Order
O(n² + n) = O(n²). O(n log n + n) = O(n log n)
Analysis Example
for (int i = 0; i < n; i++) { // Loop n times for (int j = 0; j < n; j++) { // Inner loop n times arr[i][j] = 0; // O(1) } } // Total: n * n * 1 = O(n²)
Space Complexity Analysis
O(1) Constant Space
No extra space. Variables only. Best for interviews
O(n) Linear Space
Extra array/list of size n. Common trade-off
O(log n) Space
Recursion depth. Binary search: log n call stack
O(n²) Quadratic Space
2D array or nested structures. Avoid if possible
💡 Interview Tip: Always state both time & space complexity. Space-optimized solutions (O(1) space) impress interviewers more than brute force O(n) space solutions.

Find length of longest substring with unique characters
public static int lengthOfLongestSubstring(String s) { Map<Character, Integer> map = new HashMap<>(); int left = 0, maxLen = 0; for (int right = 0; right < s.length(); right++) { if (map.containsKey(s.charAt(right))) { left = Math.max(left, map.get(s.charAt(right)) + 1); } map.put(s.charAt(right), right); maxLen = Math.max(maxLen, right - left + 1); } return maxLen; } // Time: O(n) | Space: O(min(m,n))

Example: Two Sum (Sorted Array)
Find 2 numbers that add up to target. Return indices
public static int[] twoSum(int[] nums, int target) { int left = 0, right = nums.length - 1; while (left < right) { int sum = nums[left] + nums[right]; if (sum == target) return new int[]{left, right}; else if (sum < target) left++; else right--; } return new int[]{-1, -1}; } // Time: O(n) | Space: O(1)

Example: Binary Search on Sorted Array
Find target value in sorted array
public static int binarySearch(int[] nums, int target) { int left = 0, right = nums.length - 1; while (left <= right) { int mid = left + (right - left) / 2; if (nums[mid] == target) return mid; else if (nums[mid] < target) left = mid + 1; else right = mid - 1; } return -1; } // Time: O(log n) | Space: O(1)

public static int fib(int n, Map<Integer, Integer> memo) { if (n <= 1) return n; if (memo.containsKey(n)) return memo.get(n); int result = fib(n - 1, memo) + fib(n - 2, memo); memo.put(n, result); return result; } // Time: O(n) | Space: O(n)

Real SDET Interview Scenario 1
Design: Test Retry Mechanism
Problem: Flaky tests fail randomly. Design a retry system.
class TestRetryManager { private Queue<TestCase> failedTests = new LinkedList<>(); private Map<String, Integer> retryCount = new HashMap<>(); private static final int MAX_RETRIES = 3; public void retryFailedTests() { while (!failedTests.isEmpty()) { TestCase test = failedTests.poll(); int count = retryCount.getOrDefault(test.name, 0); if (count < MAX_RETRIES) { test.run(); if (test.failed()) { failedTests.offer(test); retryCount.put(test.name, count + 1); } } } } } // Time: O(n*m) where m=max retries | Space: O(n)

class TestReporter { private Map<String, TestResult> results = new ConcurrentHashMap<>(); public void reportResult(String name, TestResult result) { results.put(name, result); } public void printStats() { int passed = 0, failed = 0; for (TestResult r : results.values()) { if (r.isPassed()) passed++; else failed++; } System.out.println("Passed: " + passed + " Failed: " + failed); } } // Time: O(n) | Space: O(n) | Thread-Safe
