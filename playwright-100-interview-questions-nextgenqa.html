What is Playwright? Who made it?
▼
Playwright is a modern, open-source browser automation framework developed by Microsoft. It allows you to write end-to-end tests and automate web browsers. It supports Chromium, Firefox, and WebKit with a single API and is available in JavaScript/TypeScript, Python, Java, and C#.

What is a Locator in Playwright? Why is it preferred?
▼
A Locator is a lazy, auto-waiting reference to an element. It does NOT immediately find the element — it finds it fresh on every action. This means it always works with dynamic DOM.

Why preferred over elementHandle:
✅ Auto-waits for actionability before actions
✅ Re-queries DOM on every action (handles dynamic elements)
✅ Works natively with expect() assertions
✅ Chainable and filterable

Where does Playwright fit in the testing pyramid?
▼
Playwright is used primarily for:

🔺 End-to-End (E2E) Tests — User workflows across the entire application
🔺 Integration Tests — Multiple components working together
🔺 API Tests — REST/GraphQL endpoint validation
🔺 Visual Tests — Screenshot comparison

It should NOT replace unit tests (use Jest/Vitest for those). Best practice: fewer E2E tests covering critical paths, more unit tests for logic.
